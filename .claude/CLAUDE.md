# Project Guidelines: CleanGrid UK
- Framework: Next.js 14+ (App Router), TypeScript, Tailwind CSS.
- Styling: Strictly follow the styling tokens, hex codes, and typography defined in DESIGN.md. Do not invent UI colors.
- Icons: Use `lucide-react`.
- API: Fetch data from `https://api.carbonintensity.org.uk/regional`.
- Workflow: Write clean, modular, typed components.
